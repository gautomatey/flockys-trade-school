# Flockys Trade School

Phone-friendly TradingView learning prototype.

Latest in this build: gold $ coin logo, 12-hour ET clocks, larger mobile tap targets, live ticker, Chart House, Pattern Zoo, Pattern Lab, Paper Desk ($1M), Safe Bag, All Hours.

## Open on a phone

After GitHub Pages is on:
https://gautomatey.github.io/flockys-trade-school/

Or open index.html next to data.js and app.js in Safari.

The one-file copy is `little-chart-school.html` — AirDrop that file if Pages is not on yet.

## Turn on Pages (one time)

Settings → Pages → Deploy from branch `main` / root → Save.
