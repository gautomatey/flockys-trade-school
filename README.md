# Flockys Trade School

Phone classroom for TradingView charts, patterns, paper options, and risk.

## Open on a phone

After GitHub Pages is on:
https://gautomatey.github.io/flockys-trade-school/

Files: `index.html` + `app.js` + `data.js`

## Turn on Pages (one time)

Settings → Pages → Deploy from branch `main` / root → Save.
Then send that Pages URL to a friend.

Tap the title on the page to rename the school.
